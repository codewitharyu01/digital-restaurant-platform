# 🍽️ My Restaurant App (Digital Restaurant Platform)

A full-stack *Django* web application designed for a modern restaurant experience. This platform features a complete user authentication system, an aesthetic dashboard, and a responsive menu display.

## ✨ Key Features
* *User Authentication:* Secure Sign Up and Login functionality using Django's built-in authentication system.
* *Aesthetic User Profile:* A custom-styled circular profile icon in the navbar that displays the first letter of the logged-in user's name.
* *Dynamic food menu dispay:* Displays updated food items with prices and categories in real time.
* *Fast Django Backend:* Ensures quick request handling and reliable server-side performance.
* *Responsive Design:* Optimized for all devices (Mobile, Tablet, and Desktop) using Bootstrap 5.


## 🛠️ Tech Stack
* *Backend:* Python, Django
* *Frontend:* HTML5, CSS3, JavaScript, Bootstrap 5
* *Database:* SQLite3 (Default)
* *Icons:* Font Awesome 6.4
